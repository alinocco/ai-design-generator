# Правила разметки планов в LabelMe

Размечаем свои 15–20 планов застройщиков — эталон для проверки распознавания (шаг 1).
Один план — 20–30 минут. Файл разметки LabelMe (`.json` рядом с картинкой)
конвертируется командой `aidesign convert-labelme`.

## Метки

| Что | Фигура LabelMe | Метка |
|---|---|---|
| Наружная стена | Rectangle или Polygon | `wall:ext` |
| Внутренняя стена, перегородка | Rectangle или Polygon | `wall` |
| Помещение | Polygon | `room:<тип>` или `room:<тип>:<площадь>` |
| Межкомнатная дверь | Line от косяка до косяка | `door` или `door:<a\|b>:<left\|right>` |
| Входная дверь | Line | `entrance` или `entrance:<a\|b>:<left\|right>` |
| Окно | Line | `window` |
| Проём без двери | Line | `passage` |
| Стояк | Point | `riser` |
| Вентканал | Point | `vent` |
| Газ | Point | `gas` |
| Масштаб | Line по известному размеру | `scale:<мм>`, например `scale:3600` |

Типы помещений: `living`, `kitchen`, `kitchen_living`, `bedroom`, `bathroom`, `toilet`,
`hall`, `corridor`, `storage`, `balcony`, `other`.

## Как размечать

1. **Масштаб.** Проведите линию `scale:<мм>` по самой длинной размерной цепочке на плане.
   Если размеров нет, но есть площади помещений — пропустите: масштаб посчитается по площадям.
2. **Стены.** Каждую стену — отдельным прямоугольником по её внешним граням, через проёмы
   не прерывайте (дверь и окно размечаются поверх). Сложный угол можно обвести одним
   Г- или Т-образным полигоном — конвертер разложит его на стены.
3. **Помещения.** Полигон по чистовым граням стен, то есть по внутреннему контуру.
   Площадь пишите так, как она подписана на плане, через запятую или точку:
   `room:bedroom:13,2`. Валидатор сравнит её с геометрией.
4. **Двери.** Линия по оси стены от косяка до косяка. Направление линии задаёт `a` и `b`:
   `a` — точка, с которой вы начали линию. Суффикс `:a:left` значит «петли у точки `a`,
   полотно открывается влево по ходу линии». Если открывание на плане не нарисовано,
   ставьте просто `door`.
5. **Стояки и вентканалы** — точкой в центре условного обозначения.

## Проверка

```bash
uv run aidesign convert-labelme plans/pik_01.json -o data/plans/pik_01.json
uv run aidesign validate data/plans/pik_01.json
uv run aidesign render data/plans/pik_01.json --issues
```

Валидатор подскажет типичные ошибки разметки: площадь не сходится с подписью, помещение
заходит в стены, дверь не стоит на стене, в помещение нельзя попасть от входа.
